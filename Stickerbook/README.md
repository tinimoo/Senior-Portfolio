# Stickerbook Introduction

This project represents a departure from my previously established interests. This project involved the creation of a new combinatorial game, Stickerbook, in which players take turns coloring squares in a grid. The player left with a grid where any available move would cause a 2x2 colored block to be formed loses.  I chose to include this presentation because it represents an occasion when a class project unexpectedly turned into a larger research project. I also presented this research in a talk at the SPROUTS conference for combinatorial game theory, my first talk ever given at a conference. I feel that this project demonstrates my curiosity for fields outside of my core interests and my mathematical range. I also feel that the presentation I gave for Stickerbook is a good example of my ability to communicate mathematics to both mathematical and general audiences. I was intentional about using colorful visual aids to make my presentation more engaging and comprehensible. This project also demonstrates my mathematical creativity in creating a new game with interesting enough properties for a worthwhile analysis. If I could do anything differently with this project, it would have been to do more research into similar games. I did not do very much digging into combinatorial games with similar rules or structures to Stickerbook, and mostly relied on my knowledge from the class. I feel my project could have been improved with greater external resources, and I will remember the importance of literature search for future work.
